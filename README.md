# Internship Task 3 - REST API

## 📌 Project Description
This project is a simple REST API built using Node.js and Express.
It performs basic CRUD operations (Create, Read, Update, Delete).

## 🚀 Technologies Used
- Node.js
- Express.js
- JavaScript
- Postman (for API testing)

## 📂 Features
- GET: Fetch all data
- GET by ID: Fetch single data
- POST: Add new data
- PUT: Update existing data
- DELETE: Remove data

## 📦 Installation & Setup

1. Clone the repository
git clone https://github.com/salmanalyy/internship-task3-rest-api.git

2. Install dependencies
npm install

3. Run the server
node server.js

Server will run on:
http://localhost:3000

## 📮 API Endpoints

| Method | Endpoint | Description |
|--------|----------|------------|
| GET | / | Welcome message |
| GET | /api/items | Get all items |
| GET | /api/items/:id | Get item by ID |
| POST | /api/items | Create new item |
| PUT | /api/items/:id | Update item |
| DELETE | /api/items/:id | Delete item |
